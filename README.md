# Марина Мороз «Iron Lady» — сайт / website

Сайт бойца UFC Марины Мороз на **русском и английском**: биография, достижения, продажа онлайн-тренировок,
консультаций и видеотренировок, восстановление ACL с физиотерапевтом, гиды по подготовке ММА и сгонке веса.

## Страницы

| Русский | English | Содержание |
|---------|---------|-----------|
| `index.html` | `en/index.html` | Главная: история, титулы и награды, победы, услуги с вкладками, способы оплаты, FAQ, форма записи |
| `training.html` | `en/training.html` | Гид «Как готовится боец ММА» |
| `weight-cut.html` | `en/weight-cut.html` | Гид «Сгонка веса на воде» |
| `acl.html` | `en/acl.html` | Гид «Восстановление ACL дома» + видеосессии с физиотерапевтом |

Переключатель **RU / EN** — в меню каждой страницы.

## Настройка — всё в `js/config.js`

1. **Контакты** (`contacts`) — Telegram, WhatsApp, Instagram, email.
2. **Услуги и цены** (`products`) — у каждой услуги тексты на двух языках (`ru` / `en`), цена и категория
   (`training`, `consult`, `video`, `acl`) — по категориям строятся вкладки на сайте.
3. **Способы оплаты** (`payments`):

   | Способ | Что вписать |
   |--------|-------------|
   | Карта Visa/Mastercard/Amex + Apple Pay + Google Pay | Создайте Stripe Payment Link для каждой услуги и вставьте в `paymentLink` услуги |
   | PayPal | `username` из ссылки paypal.me/… — сумма подставится автоматически |
   | Zelle | `recipient` (email или телефон Zelle) и `name` |
   | Venmo | `username` — сумма и назначение подставятся автоматически |
   | Cash App | `cashtag` без знака $ |
   | Wise | `email` аккаунта |
   | Monobank | `jarLink` — ссылка на банку |
   | Крипто USDT | `address` кошелька и `network` |

   Ненужный способ — поставьте `enabled: false`. Если способ включён, но реквизиты не заполнены,
   клиент увидит подсказку «реквизиты пришлю лично» и кнопки мессенджеров.
4. **`formEndpoint`** (необязательно) — адрес формы Formspree, чтобы заявки приходили на почту.

## Что ещё заполнить

- **Фото** — папка `images/` (список имён в `images/README.md`), используются обеими языковыми версиями.
- **Награда Президента** — точное название и год в `index.html` и `en/index.html`.
- **Физиотерапевт** — имя и квалификацию специалиста, проводящего ACL-сессии, лучше указать на страницах `acl.html` / `en/acl.html`.

## Публикация

Статический сайт без сборки: GitHub Pages (Settings → Pages → ветка `main`, папка `/`), Netlify, Vercel или Cloudflare Pages.

Локально: `python3 -m http.server` → http://localhost:8000
