# MARYNA MOROZ FITNESS

Двуязычная (EN / RU) фитнес-платформа украинской спортсменки UFC Марины Мороз:
видеотренировки и программы, онлайн-занятия с записью и оплатой, личные кабинеты с прогрессом
и админ-панель, в которой всё управляется без кода.

*A bilingual (English / Russian) fitness platform: paid video programs, online coaching with booking and payments,
member accounts with progress tracking and a no-code admin dashboard. Built with Next.js, SQLite/libSQL and Stripe.*

---

## Что внутри

**Сайт (`/en`, `/ru`)**
- Главная: первый экран, направления, популярные программы, «Ваш тренер», «Тренируйтесь где угодно»,
  онлайн-тренировки, видео, отзывы (только настоящие и одобренные), финальный призыв.
- 10 направлений и 16 программ: 7 программ по боксу (основы, бой с тенью, работа ног, защита, комбинации,
  боксёрское кардио, продвинутый бокс), сила и кондиция боксёра, ММА, кикбоксинг, гири, гантели, кондиция,
  мобильность, восстановление ACL, бесплатная стартовая тренировка.
- Каждое упражнение: название, описание и подсказки по технике на двух языках, подходы/раунды, время,
  место для вашего оригинального видео и превью.
- Плеер тренировки со встроенным таймером раундов (2/3/4 минуты, настраиваемый отдых) и кнопкой «Выполнено».
- Онлайн-тренировки: выбор формата → выбор времени в часовом поясе клиента → оплата → письмо с подтверждением.
- Оплата: карта, Apple Pay и Google Pay через Stripe, а также Zelle, PayPal, Venmo, Cash App, Wise, Monobank,
  криптовалюта и банковский перевод (вы подтверждаете оплату в админке).
- Личный кабинет: мои программы и прогресс, серия дней, минуты тренировок, занятия, заказы, профиль, отзыв.
  На телефоне — нижнее меню.
- Защищённые видео: смотреть платные видео может только тот, кто купил программу.
- Статьи, FAQ, юридические страницы, SEO-метаданные и hreflang для обоих языков.

**Админка (`/admin`)** — интерфейс на английском или русском (переключатель внизу меню):
- Настройки: название бренда, логотип, слоганы, цвета, тексты и фото главной, биография, контакты, соцсети,
  расписание, способы оплаты, SEO.
- Медиатека: загрузка перетаскиванием (фото и большие видео), замена, удаление, alt-тексты EN/RU,
  статус прав на использование, точка кадрирования без изменения фото, превью из кадра видео, порядок.
- Категории, программы, тренировки и упражнения: двуязычный редактор с пометками «нет перевода»,
  сортировка перетаскиванием.
- Товары и цены, заказы (подтвердить ручную оплату, отменить, отметить возврат), записи и рабочие часы,
  выходные/отпуск, пользователи (выдать доступ к программе), отзывы (модерация), достижения
  (публикуются только после вашего одобрения), статьи, FAQ, юридические страницы, журнал писем,
  отчёт о недостающих переводах.

## Быстрый старт (локально)

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env        # заполните AUTH_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm run setup               # создаёт базу и наполняет её стартовым контентом + админ-аккаунт
npm run dev                 # http://localhost:3000
```

Админка: http://localhost:3000/admin — вход с `ADMIN_EMAIL` / `ADMIN_PASSWORD` из `.env`.

Пока Stripe не подключён и `ALLOW_DEV_CHECKOUT=true`, на странице оплаты есть кнопка «Тестовая оплата» —
можно пройти весь путь покупки. **В продакшене обязательно уберите `ALLOW_DEV_CHECKOUT`.**

## Публикация

Сайт хранит базу и загруженные видео на диске, поэтому нужен хостинг с постоянным диском (Node.js):
**Railway, Render, Fly.io или любой VPS**. Vercel/Netlify без доработки не подойдут — там нет постоянного диска
для видео.

```bash
npm run build
npm run setup     # один раз на сервере
npm start
```

Для больших объёмов видео позже можно перенести файлы в облачное хранилище (S3 / Cloudflare R2 / Mux) —
весь доступ к медиа идёт через один модуль `src/lib/storage.ts` и маршрут `src/app/media/[id]`.

## Что нужно от вас

| Что | Где |
|-----|-----|
| Ключи Stripe (`STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`) и вебхук на `https://ваш-домен/api/stripe/webhook` (событие `checkout.session.completed`) | Панель Stripe → переменные окружения хостинга |
| Реквизиты Zelle, PayPal, Venmo, Cash App, Wise, Monobank, крипто | Админка → Настройки → Оплата |
| Почта для писем (`SMTP_URL`, `EMAIL_FROM`) — например, Resend, Postmark или Gmail SMTP | Переменные окружения. Без неё письма сохраняются в «Админка → Письма» |
| Свои фото и видео (только свои или с правами на использование) | Админка → Медиатека |
| Подтверждение достижений: «Мастер спорта» по боксу и кикбоксингу, сборная Украины, орден княгини Ольги (точная степень и указ) | Админка → Достижения (сейчас скрыты) |
| Проверка юристом политики конфиденциальности, условий, возвратов и медицинского дисклеймера | Админка → Юр. страницы |
| Контакты и соцсети, ваш часовой пояс и рабочие часы | Админка → Настройки, Записи и расписание |

## Важно про контент

- Сайт **не использует** фото из Google, ИИ-изображения или «фейковые» видео. Пока вы не загрузите свои материалы,
  показываются аккуратные заглушки «Фото скоро появится» / «Видео скоро появится».
- Медиа со статусом «права не подтверждены» никогда не показываются на сайте.
- Отзывы публикуются только после модерации; вымышленных отзывов нет.
- Формулировка «10+ лет в UFC» заменена на «10+ лет в профессиональном ММА»: в UFC Марина выступала в 2015–2024 (9 лет).

## Технологии

Next.js 15 (App Router, Server Actions) · TypeScript · Tailwind CSS 4 · Drizzle ORM + SQLite/libSQL (Turso) ·
Stripe Checkout · Nodemailer · jose (сессии) · bcryptjs.

Структура: `src/app/[locale]` — сайт, `src/app/admin` — админка, `src/db/schema.ts` — база,
`src/i18n` — тексты интерфейса EN/RU, `scripts/seed*` — стартовый контент.
