# Марина Мороз «Iron Lady» — сайт

Сайт бойца UFC Марины Мороз: биография, достижения, продажа онлайн-тренировок и консультаций,
гиды по подготовке ММА-бойца и сгонке веса.

## Страницы

- `index.html` — главная: история, титулы и награды, лучшие победы, тренировки с ценами, FAQ, форма записи
- `training.html` — гид «Как готовится боец ММА» (виды тренировок, Fight Camp, неделя бойца, питание, психология)
- `weight-cut.html` — гид «Сгонка веса на воде» (протокол по дням, восстановление, безопасность)

## Как настроить (5 минут)

1. **Контакты, цены, ссылки на оплату** — всё в одном файле `js/config.js`:
   - `contacts` — Telegram, WhatsApp, Instagram, email (пустые скрываются);
   - `products` — названия, цены, описания тренировок;
   - `paymentLink` — ссылка на оплату для каждой услуги (Stripe Payment Link, PayPal, WayForPay, Monobank-банка…).
     Если ссылка указана, после заявки клиент автоматически перейдёт на оплату;
   - `formEndpoint` — (необязательно) адрес формы Formspree, чтобы заявки приходили на почту.
2. **Фото** — положите в папку `images/` (список имён в `images/README.md`).
3. **Награда Президента** — впишите точное название награды и год в `index.html` (блок «Награда Президента Украины»).

## Публикация

Это статический сайт без сборки — подойдёт любой хостинг:
- **GitHub Pages:** Settings → Pages → Branch: `main`, папка `/ (root)`;
- **Netlify / Vercel / Cloudflare Pages:** просто подключите репозиторий.

Локальный просмотр: `python3 -m http.server` и откройте http://localhost:8000
