# Фотографии для сайта

Положите свои фото в эту папку с такими именами — они автоматически появятся на сайте.
Пока фото нет, на их месте показывается аккуратная заглушка.

| Файл | Где на сайте | Рекомендация |
|------|--------------|--------------|
| `hero.jpg` | Главный экран (фон) | Горизонтальное, от 1920×1080, вы справа или по центру |
| `about.jpg` | Блок «Обо мне» | Вертикальное, 4:5 (например 1200×1500) |
| `gallery-1.jpg` | Галерея (высокое) | Вертикальное |
| `gallery-2.jpg` | Галерея (широкое) | Горизонтальное |
| `gallery-3.jpg` | Галерея | Квадратное |
| `gallery-4.jpg` | Галерея (высокое) | Вертикальное |
| `gallery-5.jpg` | Галерея | Квадратное |
| `gallery-6.jpg` | Галерея (широкое) | Горизонтальное |

Используйте собственные фото или фото, на которые у вас есть права
(фотографии UFC и фотоагентств из Google защищены авторским правом).
Сжимайте фото перед загрузкой (например, на squoosh.app) — до 300–500 КБ каждое.
